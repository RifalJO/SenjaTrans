## 🚀 Cara Menjalankan

### 1. Install Dependencies

```bash
cd senja-trans-nextjs
npm install
```

### 2. Development Mode

```bash
npm run dev
```

Buka browser: **http://localhost:3000**

### 3. Build Production

```bash
npm run build
npm start
```
